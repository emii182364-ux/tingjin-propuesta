# Ting Jin Kitchenware – maqueta de propuesta

Página de ejemplo para mostrar a Ting Jin Kitchenware cómo podría verse su presencia web:
portada, catálogo con nombres claros, ficha de producto completa (TJ-82124), proceso OEM y contacto con WhatsApp.

- Trilingüe: chino tradicional (Taiwán), inglés y español, con selector en la cabecera. Se puede abrir directo en un idioma con `?lang=zh`, `?lang=en` o `?lang=es`.
- No es el sitio oficial de la empresa.
- Los datos marcados en amarillo (caudal, pedido mínimo, WhatsApp, etc.) los tiene que aportar Ting Jin.
- Las fotos se cargan desde su tienda actual en Taiwantrade (img.itaiwantrade.com); necesita conexión a internet.

## Ver en local

Abre `index.html` en el navegador. No necesita compilación ni dependencias.

## Publicar con GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
